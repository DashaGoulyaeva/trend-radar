# Contributing

Спасибо за вклад!

## Процесс

1. Создайте ветку от `master`.
2. Вносите изменения небольшими логическими коммитами.
3. Обновляйте документацию, если меняется контракт или запуск.

## Стиль

- Ясные имена и минимальные зависимости.
- Предпочитайте явные конфиги вместо магии.

## Проверка

- Запуск пайплайна: `python backend/scripts/run_pipeline.py`
- Запуск API: `python backend/scripts/serve_api.py`
- Запуск фронтенда: `npm run dev`
