# Code of Conduct

Мы ожидаем уважительное и профессиональное общение.

## Неприемлемо

- Оскорбления, дискриминация, домогательства.
- Агрессивное или уничижительное поведение.

## Принцип

Поддерживаем безопасную и продуктивную среду для всех участников.

## Сообщения о нарушениях

Сообщайте владельцу репозитория.
